# ui-helm

The styled layer of the spartan-ng components (badge, button, dialog, input,
progress), imported as `@spartan-ng/helm/*`. It is this project's own code; add
a component with `pnpm nx g @spartan-ng/cli:ui <name>`. Icons are Lucide,
drawn through the app's `app-icon` component. Do not add PrimeNG.
